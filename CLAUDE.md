# R-EDA'S STUDIO

Static landing page + booking system for a nail & make-up salon in Tirana, Albania.

## Stack

- **Frontend** — plain HTML/CSS/JS (no build step)
- **Backend** — Node.js + Express (`server.js`) serving static files and REST API
- **Database** — PostgreSQL (managed by Render in production; local pg for dev)
- **Auth** — Admin JWT via `POST /api/admin/login`, token stored in `sessionStorage`

## Project structure

```
index.html      — public landing page (hero, price list, booking calendar)
admin.html      — admin dashboard (bookings view + availability management)
styles.css      — shared design tokens and landing-page styles
booking.css     — calendar and modal styles
admin.css       — admin-only styles
booking.js      — public booking calendar (fetch-based, no localStorage)
admin.js        — admin dashboard logic (JWT auth, all API calls)
server.js       — Express server: static serving + API routes
render.yaml     — Render deployment config (web service + PostgreSQL)
assets/         — logo and any static assets
```

## Environment variables

| Variable         | Required | Description                                  |
|------------------|----------|----------------------------------------------|
| `DATABASE_URL`   | yes      | PostgreSQL connection string                 |
| `ADMIN_PASSWORD` | yes      | Admin login password (set in Render dashboard)|
| `JWT_SECRET`     | yes      | Secret for signing admin tokens (auto-generated by Render) |
| `PORT`           | no       | HTTP port (default 3000; Render sets this)   |

## Running locally

```bash
# Requires a local PostgreSQL instance or a Render dev DB URL in .env
npm install
DATABASE_URL=postgres://... ADMIN_PASSWORD=redas2024 node server.js
```

Tables are created automatically on startup (`CREATE TABLE IF NOT EXISTS`).

## Deploying to Render

1. Push to GitHub (`athanasioscanko/redas-studio`)
2. Connect repo in Render → the `render.yaml` configures everything
3. Set `ADMIN_PASSWORD` manually in the Render dashboard (Environment tab)

## Admin panel

Visit `/admin.html`. Default password is set via `ADMIN_PASSWORD` env var.

- **Bookings tab** — view upcoming / past / all bookings; cancel any booking
- **Availability tab** — block/unblock entire days or individual slots; past days are still viewable

## Time slots

`10:00 · 11:30 · 13:00 · 14:30 · 16:00 · 17:30 · 19:00` (defined in `server.js` → `SLOTS` array)
